## Product documentation

- [Product home](https://docs.pushwoosh.com/product/): Root of all product documentation.
- [First steps](https://docs.pushwoosh.com/product/first-steps/): Create a project, configure platforms, subscribe users, and understand the interface.
- [Messaging channels](https://docs.pushwoosh.com/product/messaging-channels/): Push notifications, email, SMS, in-app, Apple Wallet passes, Google Wallet passes, Web popups, WhatsApp, Telegram, LINE, Kakao, Viber, and message inbox.
- [Customer Journey](https://docs.pushwoosh.com/product/customer-journey/): Build automated omnichannel campaigns with the visual Journey Builder.
- [Audience and segmentation](https://docs.pushwoosh.com/product/audience-data-and-segmentation/): Manage user data, tags, events, and create targeted segments.
- [Content](https://docs.pushwoosh.com/product/content/): Create and manage push presets, email templates, in-app messages, and SMS content.
- [Personalization](https://docs.pushwoosh.com/product/personalization/): Dynamic content, Liquid templates, and multi-language messaging.
- [Statistics and analytics](https://docs.pushwoosh.com/product/statistics-and-analytics/): Campaign performance, dashboards, message history, and retention analytics.
- [Integrations](https://docs.pushwoosh.com/product/integrations/): Connect Pushwoosh with Amplitude, AppsFlyer, Google BigQuery, HubSpot, Shopify, Stripe, and more.
- [Pushwoosh AI](https://docs.pushwoosh.com/product/pushwoosh-ai/): ManyMoney AI in the Control Panel, ManyMoney AI MCP for planning, and Messaging MCP for sending from Claude Desktop, Cursor, and other MCP clients.
- [How-to guides](https://docs.pushwoosh.com/product/how-to-guides/): Step-by-step guides for lifecycle campaigns, personalization, and scheduling.
- [Troubleshooting](https://docs.pushwoosh.com/product/troubleshooting/): Resolve delivery errors for iOS, Android, web, email, and Huawei.
- [Release notes](https://docs.pushwoosh.com/product/release-notes/): Keep up with the latest updates in Pushwoosh. New features, improvements, deprecations, and release highlights in one place.
